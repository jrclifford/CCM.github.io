Accessibility Statement

Last Updated: July 25, 2026

Our Commitment

Clifford Construction Mediation is committed to ensuring digital accessibility for people with disabilities. We aim to conform with the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA. This statement applies to cliffordconstructionmediation.com.

Conformance Status

This website is partially compliant with WCAG 2.2 Level AA. We are actively working to improve accessibility across the site.

Accessibility Features

  • Zoom in up to 200% without loss of information or functionality
  • Full keyboard navigation throughout the site
  • Screen reader compatibility (NVDA for Windows, VoiceOver for macOS/iOS)
  • Skip navigation link for screen reader users
  • Sufficient color contrast ratios throughout
  • ARIA labels on all interactive elements
  • Mobile accessibility including AssistiveTouch (iOS) support

Known Limitations

Mobile navigation: Navigation menu links are hidden on small mobile screens. Users on mobile devices can scroll to access all content and use the footer links as an alternative. We plan to address this in a future update.

Compatible Assistive Technologies

  • Screen Readers: NVDA (Windows), VoiceOver (macOS/iOS)
  • Screen Magnification: Zoom (macOS/iOS), Magnifier (Windows)
  • Motor Assistance: Mouse Keys, Sticky Keys
  • Mobile: AssistiveTouch (iOS)

Accessibility Assistance & Alternative Formats

If you require this website's content in an alternative accessible format, or need assistance accessing any information on this site, please contact us. We will respond to accessibility requests within five business days.

Feedback

We welcome feedback on the accessibility of this site. Please let us know if you encounter barriers and we will make reasonable efforts to address them promptly.
